# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

我想做一个给潜水店使用的气瓶充填前端系统，工作人员可以记录气瓶编号、容积、检验有效期、残压、目标压力、氧含量、氦含量、充填方式和操作员。页面需要有待充填队列、混合气比例提示、气瓶检验过期提醒、充填完成签收和单个气瓶历史记录。

## 技术栈

React + Vite + TypeScript

## 分层结构

- `src/domain/` — 业务规则：入队评估（检验过期 / 残压高于目标 → 待处理区）、队列排序（氧含量 → 氦含量 → 录入先后）、配比校验、MOD 提示
- `src/store/` — 存档与状态：localStorage 持久化（带版本号），每次变更自动落盘，重开页面后队列与履历一致
- `src/components/` — 页面：前台录入、待充填队列、待处理区、充填登记（实测氧氦 / 充填方式 / 操作员 / 签收人）、今日签收、单瓶履历

## 本地运行

```bash
npm install
npm run dev
```
